# 轻提醒 · 到点就叫你

一个极简的日程提醒小工具。零依赖纯静态单页 + PWA，可安装到手机主屏、离线可用。

> 核心就三件事：**写下要提醒的事 → 选个时间 → 到点即时提醒。**

## 功能

- **输入文字**：写下要提醒的事，最长 200 字，`⌘/Ctrl + Enter` 快速添加。
- **选时间**：一排快捷时间（立即 / 5·15·30 分钟后 / 1·3 小时后 / 今晚 20:00 / 明早 09:00），也可点「指定时间」精确到分钟。
- **到点即时提醒**，三重保障：
  1. **系统通知**：授权后即使切走页面也能收到。
  2. **页面弹窗**：铃铛动画 + 提醒内容，支持「知道了」或「5 分钟后再提醒」。
  3. **提示音 + 震动**：内置 WebAudio 蜂鸣（无需音频文件），手机端配合震动。
- **本地保存**：所有提醒存在浏览器 `localStorage`，刷新或重开自动恢复未到期的提醒，**不上传任何服务器**。
- **完成 / 删除**：点圆圈标记完成，点 × 删除。
- **深色模式**：跟随系统自动切换。
- **PWA**：手机浏览器打开后「添加到主屏幕」，即可像 App 一样有独立图标、全屏运行、离线打开。

## 在手机上使用

1. 手机浏览器打开部署后的网址（见下方「部署」）。
2. **iPhone（Safari）**：点底部「分享」按钮 → 向下找到「添加到主屏幕」。
3. **安卓（Chrome）**：点右上角 ⋮ → 「添加到主屏幕 / 安装应用」。
4. 首次添加提醒时点「允许」系统通知，提醒更可靠。

## 部署（GitHub Pages，免费）

本仓库根目录即为可直接托管的静态站点：

1. 仓库 **Settings → Pages**。
2. **Build and deployment → Source** 选 **Deploy from a branch**。
3. **Branch** 选 `main`、目录选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶部会显示网址：`https://<你的用户名>.github.io/light-reminder/`。

## 本地预览

无需构建，直接用浏览器打开 `index.html`；或起本地服务（Service Worker 需要 http 环境）：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 说明与限制

- 数据只在当前浏览器、当前设备，换设备或清缓存不会同步。
- 浏览器对后台标签页定时器有节流，**页面完全关闭后系统通知不保证触发**；装成 PWA（添加到主屏）可靠性更高。要做到关机重启不丢、跨设备同步，则需要后端 + 推送服务。

## 技术

纯 HTML/CSS/JS 单文件，无框架无依赖。定时用 `setTimeout`（超长间隔自动分片重挂），提示音用 `AudioContext` 实时合成，通知用 `Notification API`，存储用 `localStorage`，离线用 Service Worker 缓存应用外壳。
