# 轻提醒 · 到点就叫你

一个极简的日程提醒小工具。零依赖纯静态单页 + PWA，可安装到手机主屏、离线可用。

> 核心就三件事：**写下要提醒的事 → 选个时间 → 到点即时提醒。**

## 功能

- **🔔 云端推送（锁屏也能收到）**：可选。部署一个免费的后端后，到点由服务器把提醒推到手机，**锁屏、App 关闭照样响**，不需要页面开着。部署步骤见 [`server/DEPLOY.md`](server/DEPLOY.md)。
- **🧠 说人话自动识别时间**：直接输入一句话，如「明天早上10点提醒我查银行卡余额，提前5分钟」，自动解析出提醒时间（09:55）、事件时间（10:00）和提醒内容，无需手动选。支持：今天/明天/后天/大后天、周几/下周几、X月X日、早上/中午/下午/晚上/凌晨、X点/X点半/X点X分/9:05、X分钟后/X小时后、以及「提前 X 分钟/小时/天」。
- **输入文字**：写下要提醒的事，最长 200 字，`⌘/Ctrl + Enter` 快速添加。
- **选时间**：也可用一排快捷时间（立即 / 5·15·30 分钟后 / 1·3 小时后 / 今晚 20:00 / 明早 09:00），或点「指定时间」精确到分钟；手动选择会覆盖智能识别。
- **到点即时提醒**，三重保障：
  1. **系统通知**：授权后 App 在后台运行时也能弹出（锁屏/关闭需配合云端推送）。
  2. **页面弹窗**：铃铛动画 + 提醒内容，支持「知道了」或「5 分钟后再提醒」。
  3. **提示音 + 震动**：内置 WebAudio 蜂鸣（无需音频文件），手机端配合震动。
- **本地保存**：提醒存在浏览器 `localStorage`，刷新或重开自动恢复未到期的提醒；不开云端推送时不上传任何服务器。
- **完成 / 删除**：点圆圈标记完成，点 × 删除。
- **深色模式**：跟随系统自动切换。
- **PWA**：手机浏览器打开后「添加到主屏幕」，即可像 App 一样有独立图标、全屏运行、离线打开。

## 在手机上使用

1. 手机浏览器打开部署后的网址（见下方「部署」）。
2. **iPhone（Safari）**：点底部「分享」按钮 → 向下找到「添加到主屏幕」。
3. **安卓（Chrome）**：点右上角 ⋮ → 「添加到主屏幕 / 安装应用」。
4. 首次添加提醒时点「允许」系统通知，提醒更可靠。

## 部署（GitHub Pages，免费）

本仓库根目录即为可直接托管的静态站点：

1. 仓库 **Settings → Pages**。
2. **Build and deployment → Source** 选 **Deploy from a branch**。
3. **Branch** 选 `main`、目录选 `/ (root)`，点 **Save**。
4. 等一两分钟，页面顶部会显示网址：`https://<你的用户名>.github.io/light-reminder/`。

## 本地预览

无需构建，直接用浏览器打开 `index.html`；或起本地服务（Service Worker 需要 http 环境）：

```bash
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 说明与限制

- 提醒数据存在本机浏览器；开启云端推送后，**待提醒**会同步到你自己部署的后端。
- **不开推送时**：页面被关闭或手机锁屏后，网页会被系统冻结，到点不会弹通知（打开 App 才会补弹）。这是网页的固有限制。
- **开了推送后**：由服务器在到点时主动推送，锁屏和 App 关闭都能收到；定时任务每分钟扫描一次，可能有最多约 1 分钟延迟。
- iOS 接收推送要求先把页面「添加到主屏幕」，并从桌面图标打开。

## 项目结构

```
index.html   前端（单文件，可直接部署到 GitHub Pages）
sw.js        Service Worker：离线缓存 + 接收推送
server/      推送后端（Cloudflare Worker），见 server/DEPLOY.md
```

## 技术

前端：纯 HTML/CSS/JS 单文件，无框架无依赖。定时用 `setTimeout`（超长间隔自动分片重挂），提示音用 `AudioContext` 实时合成，通知用 `Notification API`，存储用 `localStorage`，离线用 Service Worker（网络优先）缓存应用外壳。

后端：Cloudflare Worker + D1 + Cron Trigger。Web Push 的 `aes128gcm` 加密与 VAPID 签名为自行实现（纯 WebCrypto、零依赖）——常见的 `webpush-webcrypto` 只支持旧版 `aesgcm`，而 iOS 只接受 `aes128gcm`。相关往返解密测试见 `server/test/push.test.mjs`。
